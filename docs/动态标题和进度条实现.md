# 动态标题和进度条实现说明

本文档说明如何实现动态标题更新和进度条显示，而不会导致扩展自动锁定。

## 问题背景

之前的实现中：
1. 使用 `IsLoading = true/false` 来显示进度会导致扩展自动锁定
2. 同步和锁定操作没有进度指示
3. 标题更新与 `IsLoading` 状态耦合

## 解决方案

参考 Video Downloader 扩展的实现，采用以下方案：

### 1. ExtensionHost 静态单例

创建 `ExtensionHostHelper` 类来存储 `IExtensionHost` 实例：

```csharp
// Helpers/ExtensionHostHelper.cs
internal static class ExtensionHostHelper
{
    public static IExtensionHost? Instance { get; set; }
}
```

在 `CommandsProvider` 中注册：

```csharp
public override void InitializeWithHost(IExtensionHost host)
{
    ExtensionHostHelper.Instance = host;
}
```

### 2. 事件驱动的标题更新

在 `BitwardenCliService` 中添加事件：

```csharp
public event Action<string>? TitleUpdated;
public event Action? StatusChanged;
```

在 `SyncAsync` 和 `LockAsync` 中触发事件：

```csharp
public async Task<bool> SyncAsync()
{
    TitleUpdated?.Invoke("Syncing vault...");
    // ... 执行同步
    StatusChanged?.Invoke();
    return success;
}
```

在主页面中订阅事件：

```csharp
public BitwardenForCommandPalettePage()
{
    var service = BitwardenCliService.Instance;
    service.TitleUpdated += OnTitleUpdated;
    service.StatusChanged += OnStatusChanged;
}

private void OnTitleUpdated(string title)
{
    Title = title;  // 直接更新标题，不触碰 IsLoading
}
```

### 3. StatusMessage 进度条

使用 `StatusMessage` 显示进度条和状态横幅：

```csharp
public override CommandResult Invoke()
{
    // 创建状态消息
    var statusMessage = new StatusMessage
    {
        Message = "Syncing vault...",
        State = MessageState.Info,
        Progress = new ProgressState { IsIndeterminate = true }
    };

    // 显示状态横幅
    statusMessage.ShowStatus();

    // 执行操作
    bool success = BitwardenCliService.Instance.SyncAsync().GetAwaiter().GetResult();

    // 更新状态
    if (success)
    {
        statusMessage.Message = "Vault synced";
        statusMessage.State = MessageState.Success;
        statusMessage.Progress = null;
    }

    // 自动隐藏
    _ = Task.Run(async () =>
    {
        await Task.Delay(3000);
        statusMessage.Hide();
    });

    return CommandResult.KeepOpen();
}
```

### 4. StatusMessage 扩展方法

创建扩展方法简化使用：

```csharp
// Helpers/StatusMessageExtensions.cs
internal static class StatusMessageExtensions
{
    public static void ShowStatus(this StatusMessage message)
    {
        ExtensionHostHelper.Instance?.ShowStatus(message, StatusContext.Extension);
    }

    public static void Hide(this StatusMessage message)
    {
        ExtensionHostHelper.Instance?.HideStatus(message);
    }
}
```

## 关键要点

1. **不要使用 IsLoading**：直接更新 `Title` 属性，通过事件机制解耦
2. **使用 StatusMessage**：显示进度条和状态横幅，不影响扩展状态
3. **事件驱动**：服务层触发事件，UI 层订阅响应
4. **自动隐藏**：成功/失败状态 3-5 秒后自动隐藏

## 效果

- ✅ 同步时显示 "Syncing vault..." 标题和不确定进度条
- ✅ 锁定时显示 "Locking vault..." 标题和不确定进度条
- ✅ 完成后显示成功/失败消息，3 秒后自动隐藏
- ✅ 标题动态更新显示最后同步时间
- ✅ 不会导致扩展自动锁定
